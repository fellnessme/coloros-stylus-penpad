# 03 · 把系统原生的全局批注打开

ColorOS 自带一个「笔从屏幕底边上滑 → 截图/批注」的功能。在非 OPPO 设备上它默认是关的，
日志里能看到的只有：

```
GestureLog_OplusPenGestureManager: updatePencilSwipFunction mode=SWITCH_CLOSE, activeStrategy=A_GLOBAL_ANNOTATION
```

## 怎么找到那个开关

系统侧的逻辑在 `/system/framework/oplus-services.jar`（`OplusPenGestureManager`）。
把它拉下来，在字符串表里搜 `pencil`：

```
IPE_PENCIL_SWIP_FUNCTION          ← 常量名
IPE_PENCIL_SWIP_FUNCTION_URI
ipe_pencil_swipe_function         ← 实际的 settings key（小写）
```

**常量名是大写，settings key 是小写，两者不一样。** 这是整件事最容易卡住的地方。

## 打开

```bash
settings put global ipe_pencil_swipe_function 1
```

然后用笔在屏幕上碰一下触发刷新，日志立刻变成：

```
GestureLog_OplusPenGestureManager: updatePencilSwipFunction mode=SCREENSHOT_OPEN, activeStrategy=A_GLOBAL_ANNOTATION
GestureLog_OplusPenGestureManager: isPenScreenshotEnable = 1
```

## 用法

**用笔从屏幕最底边（贴着边缘）快速往上滑 4~5 厘米**，就会唤起 `com.oplus.screenshot/LongshotMark`。

起手区很小（日志里 `mSwipeStartAreaWidth:131`，即 131px），所以：

- 必须贴着底边起手
- 滑动要够快够长（`mTouchSlop:21`）

## 同族的其它键（未全部验证）

从同一份 jar 里还能找到这些 key，值得一试：

| key | 猜测用途 |
|---|---|
| `ipe_palm_rejection` | 掌压抑制 |
| `ipe_pencil_present` | 笔在位检测 |
| `ipe_quick_notes_state` | 息屏速记 |
| `ipe_laser_mode` | 激光笔模式 |
| `ipe_setting_only_laser_enable` | 只允许激光笔 |
| `settings_enable_nobtpencil` | 非蓝牙笔支持 |

## 这个界面有压感吗

**没有。** 扫 `com.oplus.screenshot` 的 6 个 dex：

```
getPressure            出现 1 次
getHistoricalPressure  出现 1 次
TOOL_TYPE_STYLUS       出现 0 次
```

它设计上就是「快速框选标注」，笔宽固定。想加压感只能重打包系统应用，风险远大于收益。

**需要压感就用本项目的 PenPad。**
