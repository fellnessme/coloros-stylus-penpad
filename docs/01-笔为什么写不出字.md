# 01 · 手写笔为什么完全写不出字

## 症状

- 笔在别的设备上正常，在这台机器上任何 App 都收不到压感
- 系统设置里「手写笔」页面是灰的，点不动
- `dumpsys input` 能看到笔设备，但触摸事件不带真实压力

## 根因

ColorOS 有一个**全局手写笔开关**，默认关。开关关闭时，数字化仪只上报「手指级」的触摸，
不报真实接触面积、压力和悬停。

这个开关在 **`Settings.Global`** 命名空间：

```bash
settings get global settings_enable_oppo_pencil
# 0
```

注意**不是** `Settings.Secure`。很多资料写错了命名空间，导致一直改不动。

## 修复

```bash
settings put global settings_enable_oppo_pencil 1
```

设完立刻生效，不需要重启。用笔在屏幕上写，`getevent` 就能看到 `ABS_PRESSURE` 从 0 变成真实值。

## 但它会自己变回 0

实测以下几种情况会被重置：

- 重启
- 系统清理后台
- 某些系统服务重新初始化

重置后表现就是「笔突然写不出字」，很像笔没电或者断连。

### 怎么守

需要一个常驻进程定期把它写回 1。本项目里是 `PenKeyService`（无障碍服务）里的一个 3 秒循环：

```java
int v = Settings.Global.getInt(cr, "settings_enable_oppo_pencil", -1);
if (v != 1) Settings.Global.putInt(cr, "settings_enable_oppo_pencil", 1);
```

**前提是进程有 `WRITE_SECURE_SETTINGS` 权限**，普通应用拿不到，见 README 的「特权安装」。
